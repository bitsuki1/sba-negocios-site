## 4. Como retomar / publicar
1. `npm install && npm run dev` (porta 8080).
2. Conteúdo em `src/data/site.ts` e `src/data/landings.ts`; páginas em `src/pages/`.
3. **Publicar (host oficial = VERCEL):** basta **`git push` na `main`** — a Vercel faz o deploy de produção
   automático. Nada manual. O `npm run build` (que a Vercel roda) já encadeia o pré-render de OG
   (`scripts/prerender-og.mjs`), gerando um `index.html` por rota.
   - *Fallback GitHub Pages (só até o cutover de DNS):* `bash scripts/deploy-producao.sh` — publica na `gh-pages`.
     O script agora avisa que é legado; após o cutover, pode ser removido junto com a branch `gh-pages`.
4. Leads: Edge Function `submit-lead` no Supabase (projeto `gestao-integrada-dados`, tabela `sba_leads`) + fallback e-mail.
   **Fonte versionada em `supabase/functions/submit-lead/index.ts`** (sem chave — segredos só no Supabase; deploy com `supabase functions deploy submit-lead`).
